# 陀螺儀賽車 3D · Gyro Racer

用手機陀螺儀控制的 3D 賽車遊戲。Three.js 全 3D：低多邊形賽車、封閉賽道、護欄、樹木、起跑拱門。

🎮 **線上遊玩**：https://hebe2234.github.io/gyro-racer/

## 玩法

- **操作**：左右傾斜手機＝轉方向盤（iPhone 首次會要求陀螺儀權限，請按允許）
- **油門**：預設自動加速；右下角紅色按鈕＝煞車（過彎用）
- **目標**：無限繞圈，挑戰最速單圈（右上小地圖＋圈速 HUD）
- 沒有陀螺儀的裝置會自動顯示 ◀ ▶ 觸控轉向鈕；電腦可用 ← → ↑ ↓ 方向鍵

## 技術

- Three.js（CDN）程序化建模，無外部素材
- 賽道：封閉 Catmull-Rom 曲線（centripetal，無自交），555 公尺
- 街機式物理：速度/轉向/擦牆減速；賽道約束用中心線投影夾取
- WebAudio 合成引擎聲（隨速度變調），可靜音
- `?autostart=1` 跳過開始畫面（自動測試用）、`?debug=1` 顯示錯誤日誌

## 本機開發

直接用靜態伺服器開啟即可（需連網載入 Three.js CDN）：

```bash
python3 -m http.server 8000
# 瀏覽器開 http://localhost:8000/
```
